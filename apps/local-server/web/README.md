# web/

Build output of the editor bundle that this binary embeds with `go:embed`.
It is generated by `pnpm build:local` from the repository root (the Vite
composition in `apps/editor/vite.local-web.config.ts` writing
`apps/editor/dist-local`, copied here). This README is the only tracked
file, so a fresh checkout can compile and test the server before the
editor bundle exists; running the server without a built bundle answers
every route with a startup error instead.
